# Workout Music Player

This is a web-based workout music player that generates dynamic workout music based on different styles and intensity levels.

## Accessing the Player

You can access the player at: `https://your-username.github.io/hiit-timer/workout-music/`

## Features

- Multiple music styles (EDM, Rock, Hip Hop)
- Adjustable BPM (beats per minute)
- Intensity control
- Real-time audio visualization
- Responsive design

## Controls

- **Play/Pause**: Start or pause the music
- **Style**: Change the music style
- **BPM**: Adjust the tempo
- **Intensity**: Control the energy level of the music

## Development

This is a static web application that runs entirely in the browser using the Web Audio API.
